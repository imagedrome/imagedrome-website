# imagedrome-website

Static company landing for [imagedrome.com](https://imagedrome.com) — same Beyo poster layout as Broong.com / Beyo.day, without Privacy Policy.

Brand names **Imagedrome / 이미지드롬** in metadata/JSON-LD. HTML + CSS only; email uses a click-time `mailto:` assembly.

## Deploy

Cloudflare Pages → this repo root. No build step.
